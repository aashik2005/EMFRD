                    TO RUN THIS PROJECT
═══════════════════════════════════════════════════════════════════

╔═══════════════════════════════════════════════════════════════════╗
║  STEP 1: Install Python (5 minutes) - REQUIRED                   ║
╚═══════════════════════════════════════════════════════════════════╝

1. Open browser: https://www.python.org/downloads/

2. Click: "Download Python 3.11.x" (or 3.12.x)

3. Run the installer

4. ⚠️  CRITICAL: Check the box "Add Python to PATH"
   This is at the bottom of the first installer screen!

5. Click "Install Now"

6. Wait for installation to complete

7. ⚠️  Close and reopen your terminal/command prompt

8. Verify installation:
   Type: python --version
   Should show: Python 3.11.x or 3.12.x


╔═══════════════════════════════════════════════════════════════════╗
║  STEP 2: Run Automated Setup (10 minutes)                        ║
╚═══════════════════════════════════════════════════════════════════╝

Double-click: setup.bat

This will automatically:
  - Create virtual environment
  - Install PyTorch, Transformers, FastAPI
  - Install React dependencies
  - Verify everything works


╔═══════════════════════════════════════════════════════════════════╗
║  STEP 3: Start the System (Instant)                              ║
╚═══════════════════════════════════════════════════════════════════╝

Double-click: run.bat

This will:
  - Start Backend at http://localhost:8000
  - Start Frontend at http://localhost:5173
  - Open 2 terminal windows


╔═══════════════════════════════════════════════════════════════════╗
║  STEP 4: Open in Browser                                         ║
╚═══════════════════════════════════════════════════════════════════╝

Open: http://localhost:5173

You'll see the EMFRD dashboard!
